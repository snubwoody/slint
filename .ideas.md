# Ideas for speeding up compilation

Specifically changing the slint compiler so that rustc has a better time during incremental compilation.

- Split files: Everything is generated as one big `app.rs`, not much room for incremental compilation. Splitting by file or types could help. Maybe all globals in one file, components in another?
- Re-use component names/structs. It seems as though some (every) components get their numbered struct e.g. `InnerPrimaryButton23`, if so that would probably generate quite a lot of code. Actually this might be so that the names don't clash, but maybe properties could be shared?
- Runtime layout, slint computes layout at compile time. Moving this runtime calculations should speed up compilation as less code would need to be generated.
